# Cedia bloub-nuage mark — v1

Owner-supplied logo (`source.png`, 1024 px RGBA): dark cloud body on
transparency with white eyes. Adopted October 2026, replacing
`cedia-terminal-d-v1`.

- `source.png` is the exact owner file copied from
  `/Users/pond/Downloads/bloub-nuage-attentif-encre.png` (no redraw).
- `cedia-mark.png` is the black mark with transparent background and
  transparent eye knockouts (anti-aliased edges preserved).
- `cedia-mask.png` is the corresponding white luminance mask on transparency.
- `mark.svg`, `cedia.svg`, and the light/dark SVGs embed the same mask.
- `app-light.svg` / `app-dark.svg` are exact inverses: white background with
  black mark, and black background with white mark. Eye knockouts show the
  background through, so dark mode reads as an inverted cloud.
- `app-macos.svg`, `cedia.iconset/`, and `cedia.icns` provide the rounded macOS
  app icon and standard platform sizes. The macOS tile uses `cedia-mask-macos.png`
  (blob scaled to 82% centered) so the white tile keeps breathing room at Dock sizes.
- `app-light.png` and `app-dark.png` are 1024 px square app-icon masters; iOS
  appearance-specific catalog images use these exact files.
- All derived assets and existing app copies are regenerated by
  `scripts/generate-brand-icons.ts` (SVG + `sips` + `iconutil`, no FFmpeg
  extraction — the source is already separated).

The monochrome identity stays flat with no glow or shadow.
