# Cedia Mark A — approved reference

The owner approved option A on September 26, 2026. `approved-reference-board.png` is the exact
flat light/dark comparison board selected in this thread. The production mark is extracted from
the left light icon in that board, preserving its silhouette and terminal knockout instead of
redrawing them.

- `cedia-mark.png` is the black mark with transparent background and transparent `>I` knockout.
- `cedia-mask.png` is the corresponding white luminance mask on transparency.
- `mark.svg`, `cedia.svg`, and the light/dark SVGs embed the same extracted mask.
- `app-light.svg` and `app-dark.svg` use exact inverse black/white colors.
- `app-macos.svg`, `cedia.iconset/`, and `cedia.icns` provide the rounded macOS app icon and
  standard platform sizes.
- `app-light.png` and `app-dark.png` are 1024 px square app-icon masters; iOS appearance-specific
  catalog images use these exact files.
- All derived assets and existing app copies are generated by `scripts/generate-brand-icons.ts`.
  The generator uses FFmpeg, `sips`, and `iconutil`.

The mark geometry is raster-sourced from the approved 586 px reference and retained at 1024 px
for the shipped masters. The monochrome identity is intentionally flat with no glow or shadow.
